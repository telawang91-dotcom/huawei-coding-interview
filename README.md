## 🚀 面试前复习顺序

**第一优先级：** 哈希 → 双指针 → 链表 → 二叉树 / BFS / DFS → 栈  
**第二优先级：** 数组 → 滑动窗口 → DP  
**第三优先级：** Hard 题重点理解思路，不强求第一次就完整默写。

## 🧠 推荐使用方式

1. 只看题名，先判断题型。
2. 30 秒说出核心方法。
3. 点击“原图”核对速记口诀、代码和复杂度。
4. 再关掉答案，独立手写一次核心代码。
