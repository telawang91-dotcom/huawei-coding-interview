## 🚀 建议复习顺序

**第一优先级：** 哈希 → 双指针 → 链表 → 二叉树 / BFS / DFS → 栈  
**第二优先级：** 数组 → 滑动窗口 → DP  
**第三优先级：** Hard 题重点理解思路，不强求一遍默写完整代码。

## 🧠 使用方式

1. 先看题目，尝试 30 秒说出题型和核心方法。
2. 再看图中的“速记口诀 / 核心思路”。
3. 最后只看题名，手写核心代码。
4. 面试前重点复习每题的复杂度和关键边界条件。
